=========================================
ШПАРГАЛКА GIT: ЕЖЕДНЕВНЫЙ ЦИКЛ СОХРАНЕНИЯ
=========================================

ВАЖНО: Все команды вводятся строго из корневой папки проекта (там, где лежит скрытая папка .git)!

ШАГ 1. ПРОВЕРКА (Опционально, но полезно)
Посмотреть, какие файлы были изменены:
> git status

ШАГ 2. ПОДГОТОВКА ФАЙЛОВ
Добавить ВСЕ измененные файлы в корзину для сохранения:
> git add .
(Точка на конце обязательна, она означает "всё в этой папке")

ШАГ 3. СОЗДАНИЕ СЛЕПКА (КОММИТ)
Упаковать добавленные файлы и повесить ярлык с описанием:
> git commit -m "Кратко и понятно описать, что сделал"

ШАГ 4. ОТПРАВКА НА СЕРВЕР (GITHUB)
Отправить готовый коммит в интернет:
> git push

-----------------------------------------
ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ (ДЛЯ КОМАНДНОЙ РАБОТЫ):

* Скачать свежие изменения от напарника из интернета:
> git pull

* Создать новую ветку для своей задачи и сразу перейти в нее:
> git checkout -b название_ветки
(Например: git checkout -b feature/calendar)

* Если делаешь push в НОВУЮ ветку В ПЕРВЫЙ РАЗ, Git попросит:
> git push -u origin название_ветки
